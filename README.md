# Heim-WMS – Home Assistant Add-on Repository

Persönliche Lagerverwaltung als lokales Home-Assistant-Add-on.

## Installation

1. In Home Assistant: **Einstellungen → Add-ons → Add-on-Store**.
2. Oben rechts **⋮ → Repositories**.
3. Diese Repository-URL hinzufügen:
   ```
   https://github.com/mhoeglin/ha_logistik
   ```
4. Nach dem Hinzufügen erscheint **Heim-WMS** im Store → **Installieren**.
5. Optional unter *Konfiguration* `seed_demo_data: true` setzen, um Beispieldaten
   anzulegen. Danach **Starten** und **In Seitenleiste anzeigen** aktivieren
   (Zugriff per Ingress).

Details siehe [`heimwms/DOCS.md`](heimwms/DOCS.md).
