Abläufe & Scan-Prozeduren

Prinzip: Du scannst zuerst ein Kommando (vom Kommando-Blatt), dann bei Bedarf einen Lagerort, dann die Artikel. Jeder Ort hat nur einen Aufkleber; die Aktionen liegen einmal global auf dem Kommando-Blatt.

Code-Typen: CMD:… Kommando (Aktion) · LOC:xxxxxx Lagerort · ITM:xxxxxx Artikel/Karton
Orts-Richtung (geplant): normal (rein/raus) · Senke (nur rein, z.B. Mülleimer) · Quelle (nur raus, z.B. Neukauf-Eingang)

1. Einlagern aktiv

Kommando CMD:STORE → Ort → Artikel nacheinander.

flowchart LR
  A["Scan CMD:STORE"] --> B["Scan Lagerort LOC:…"]
  B --> C["Scan Artikel ITM:…"]
  C --> C
  C --> D["Zuordnung + Historie
in der DB"]

2. Auslagern geplant

Artikel verlässt seinen Ort, bleibt aber erhalten (Status „ausgelagert").

flowchart LR
  A["Scan CMD:REMOVE"] --> B["Scan Artikel ITM:…"]
  B --> B
  B --> C["Aktiver Standort entfernt
Status: ausgelagert
Historie: REMOVE"]

3. Umzug (Ort → Ort) geplant

Neuer Zielort, dann die Kisten – jede wird dem neuen Ort zugeordnet.

flowchart LR
  A["Scan CMD:MOVE"] --> B["Scan neuer Ort LOC:…"]
  B --> C["Scan Artikel ITM:…"]
  C --> C
  C --> D["Alter Standort inaktiv
neuer Standort aktiv
Historie: MOVE"]

4. Ausleihen / Zurückgeben geplant

Werkzeug verlässt das Lager (ausgeliehen) und kommt später zurück.

flowchart LR
  subgraph Ausleihen
    A1["Scan CMD:LEND"] --> A2["Scan Artikel ITM:…"]
    A2 --> A3["Status: ausgeliehen
(optional: an wen)"]
  end
  subgraph Zurückgeben
    B1["Scan CMD:RETURN"] --> B2["Scan Artikel ITM:…"]
    B2 --> B3["Status: verfügbar
zurück am Ort"]
  end

5. Wegwerfen (Senke) & Neukauf (Quelle) geplant

Ein Mülleimer ist ein Ort mit nur einer Richtung (Senke): was hier eingelagert wird, gilt als entsorgt. Ein Neukauf-Eingang ist eine Quelle: von hier entsteht neuer Bestand. 

flowchart LR
  subgraph Wegwerfen
    W1["Scan CMD:STORE"] --> W2["Scan Ort = Senke
(z.B. LOC Mülleimer)"]
    W2 --> W3["Scan Artikel ITM:…"]
    W3 --> W4["Status: entsorgt
kein aktiver Standort
Historie: DISPOSE"]
  end
  subgraph Neukauf
    N1["Artikel anlegen ITM:…"] --> N2["Scan CMD:STORE"]
    N2 --> N3["Scan normaler Ort LOC:…"]
    N3 --> N4["Status: eingelagert
Historie: ACQUIRE/STORE"]
  end
